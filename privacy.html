MarginHop Privacy Policy

This policy applies to the MarginHop Windows desktop app, version 0.1.2.

Your notes on this device

You can use MarginHop without an account. MarginHop stores your notes, notebook reference codes, tags, source links, drafts, settings, and note activity dates on your computer. Search and Java writing suggestions run on your device. MarginHop does not send your notes, searches, or typing to the publisher. The app contains no advertising, usage analytics, or automatic crash-reporting service.

Backups you choose

Exporting a backup writes a readable file to the location you select. If you choose a shared or cloud-synced folder, that folder’s access and sync settings apply. MarginHop does not encrypt its local database or exported backup files.

GitHub backup is optional. If you connect it, MarginHop sends your repository details and uses your access token to make requests to GitHub. A manual or automatic backup writes a copy of your saved library to the repository, branch, and file you select. This includes note contents, codes, tags, source information, timestamps, and reserved codes. People with access to the repository may be able to read the backup. The app stores the token in Windows Credential Manager and excludes it from backup files. GitHub processes requests under its own privacy statement: GitHub General Privacy Statement

Your choices and deletion

You can edit or delete notes, turn off automatic backup, or disconnect GitHub in Settings. Disconnecting removes the saved connection and token from MarginHop. It leaves uploaded files and repository history in place. You can also revoke the token in GitHub. Deleting a note can leave older copies in local recovery snapshots, exported files, or GitHub history. MarginHop retains deleted reference codes to prevent their reuse.

To remove your local library and recovery snapshots, locate the data folder under Settings → Local data & recovery, close MarginHop, and delete that folder. Delete any exports separately. Manage remote copies and their history through GitHub.

Links, clipboard, and support

Opening an external link sends it to your default browser. Using a Copy action puts the selected content on the Windows clipboard, where your Windows clipboard settings apply. For privacy questions, use the publisher support contact on MarginHop’s Microsoft Store listing. You can ask a privacy question without sending your notes or GitHub token.
